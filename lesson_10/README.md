# Lesson 10. Page Object + Allure

## Описание проекта

Проект содержит UI-автотесты, написанные с использованием паттерна "Page Object".

В проекте реализованы два тестовых сценария:
- проверка работы калькулятора;
- проверка оформления заказа в интернет-магазине.

Для автоматизации используется Selenium WebDriver, запуск тестов выполняется через Pytest, а результаты отображаются в Allure Report.

## Используемые технологии:

- Python
- Selenium WebDriver
- Pytest
- Allure Report
- Flake8

## Установка проекта

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

Для запуска тестов с формированием результатов Allure выполните команду:

```bash
pytest --alluredir=allure-results
```

После выполнения команды будет создана папка **allure-results**, в которой сохраняются результаты выполнения тестов.

## Просмотр Allure-отчёта

Для просмотра отчёта выполните команду:

```bash
allure serve allure-results
```

После выполнения команды отчёт автоматически откроется в браузере.

## Проверка соответствия PEP8

Для проверки стиля кода выполните:

```bash
flake8 lesson_10
```

Если команда не выводит сообщений, значит код соответствует требованиям PEP8.

## Описание тестов

### Тест «Калькулятор»

Проверяется:

- открытие страницы калькулятора;
- установка задержки 45 секунд;
- выполнение вычисления `7 + 8`;
- получение результата `15`.

### Тест «Интернет-магазин»

Проверяется:

- авторизация пользователя;
- добавление товаров в корзину;
- переход к оформлению заказа;
- заполнение данных покупателя;
- проверка итоговой стоимости заказа `$58.29`.

## Allure

В тестах используются:

- `@allure.title`
- `@allure.description`
- `@allure.feature`
- `@allure.severity`
- `with allure.step()`
